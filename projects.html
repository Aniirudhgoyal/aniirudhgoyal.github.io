LOB Mid-Price Prediction

Predicting short-term mid-price direction on NASDAQ AAPL using limit order book microstructure features and gradient boosting. Trained a LightGBM multiclass classifier on 280K events of LOBSTER tick data with 36 engineered features — order-flow imbalance variants, microprice signal, rolling volatility, message-flow rates, and inter-event timing. Properly evaluated with time-based splits, macro-F1, and per-trade Sharpe with explicit spread-cost analysis.

Bio-Diesel Yield Prediction

Compiled a face-centered CCD dataset (29+ runs) from published literature; benchmarked Linear Regression, Random Forest, and AdaBoost for yield + FFA conversion. AdaBoost won with R² = 0.97, MSE ≈ 0.25. Used the model to recommend optimal reaction conditions (time, temperature, methanol:oil ratio) for 95%+ yield.
